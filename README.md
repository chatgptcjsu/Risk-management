# 안전온 — 위험성평가 플랫폼 미리보기

## 프로젝트 개요
위험성평가의 작성, 검토·승인, 개선조치 추적과 연도별 문서 보관을 지원할 플랫폼의 화면 프로토타입입니다.
현재 화면은 요구사항 확인을 위한 샘플 UI이며, Spring Boot·MariaDB 백엔드와 연결되어 있지 않습니다.

## 현재 구현된 화면
- 청주공장 위험성평가 대시보드 및 KPI 카드
- 정기 / 수시 평가 유형 필터와 샘플 평가 목록 검색
- Excel형 위험성평가를 먼저 작성하고, 위험도 8점 이상 항목에 대해 PPT형 평가를 추가 작성하는 순서
- 위험도 8 이상 우선 개선 항목 자동 선별 및 후속 PPT 작성 목록
- 승인 대기, 최근 활동, AI 사진분석 진입 UI
- 모바일 화면용 사이드바와 반응형 레이아웃
- Excel 평가표 형식의 행 추가형 입력 (작업내용, 유해 위험요인, 현재 상태·조치, 빈도, 강도, 감소대책, 개선 후 예상 위험도, 날짜, 담당자, 비고)
- 빈도 1~5 × 강도 1~4로 현재 위험도를 자동 계산하고, 8점 이상 행 강조
- 위험도 8점 이상 행만 PPT 추가 작성 목록에 표시
- PPT 양식에 위험요인·재해형태·개선대책, 개선 전·후 사진 입력 및 미리보기
- 개선 전 빨간색 위험도는 Excel 점수와 일치하는 매트릭스 셀에서 선택, 개선 후 초록색 위험도 순차 선택
- 위험등급 자동 입력, ③ 초기화, 위험등급 기준표 표시
- PPT 진행 단계: 8점 이상 위험 → 현장 확인 및 협의 중 → 공무팀 검토 → 공사진행 → 공사 검토 → 공사완료
- PPT 진행 표시: 8점 이상 위험 → 현장 확인 및 협의 중 → 공무팀 검토 → 공사진행 → 공사 검토 → 공사완료
- 개선 예정일 달력, 담당자, 참여자 이름, 비고 입력
- `/health` 상태 확인 엔드포인트

## 진입 경로
- `/` : 대시보드 화면
- `/health` : `{ "status": "ok", "app": "safety-on-preview" }`

## 아직 연결되지 않은 기능
- 로그인 및 사용자별 조회/수정/승인 권한
- Spring Boot API와 MariaDB 영속 저장 (현재 새 평가는 브라우저 미리보기 상태이며 서버 저장되지 않음)
- 사진 파일의 서버 저장 및 실제 위험성평가 생성·수정, 승인 워크플로
- 현장 사진 업로드와 AI 위험요인 분석
- 평가 입력·사진 및 고위험 후속 PPT의 서버 저장 (현재 브라우저 미리보기 상태)
- 위험도 계산·8점 이상 자동 선별은 현재 클라이언트에서 수행되며 서버 검증은 미구현
- 연도별 평가 검색, 엑셀/PPT 파일 생성 및 내려받기

## 실행 방법
```bash
cd /home/user/webapp
npm run build
pm2 start ecosystem.config.cjs
```
미리보기는 샌드박스 포트 3000에서 실행합니다. PM2 로그는 `pm2 logs webapp --nostream`으로 확인할 수 있습니다.

## 기술 및 배포 상태
- 현재 미리보기: Hono + Vite + TypeScript/TSX
- 목표 서비스: Java 17 + Spring Boot + MariaDB
- 저장소: `https://github.com/chatgptcjsu/Risk-management` (`text1015` 개발 브랜치)
- Cloudflare Pages는 Spring Boot 서버 호스팅 대상이 아니므로 실제 배포 시 별도 Java 지원 호스팅 환경이 필요합니다.
